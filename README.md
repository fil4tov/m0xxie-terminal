# M0XXIE — Phosphor

Личный сайт-терминал на **React + TypeScript + Vite**, с кассетным плеером на Three.js и иконками React Icons (Feather и Simple Icons). Реализован выбранный первый вариант: зелёный CRT-экран и тёмный корпус MX–90.

## Локальный запуск

Требуется Node.js 22.12+ или 24+.

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:4173/. `npm start` запускает тот же сервер. Изменения отображаются автоматически.

```sh
npm test          # проверки терминала и аудиоуправления
npm run typecheck # строгая проверка TypeScript
npm run build     # готовая сборка в dist
npm run preview   # просмотр сборки после остановки dev-сервера
```

## Управление

Ввести `/` для подсказок. Команды: `/github`, `/bandcamp`, `/listen`, `/help`, `/clear`. Стрелки выбирают подсказки или возвращают историю ввода, Tab дополняет, Enter выполняет, Escape закрывает меню. Ответы печатаются посимвольно. Системная настройка уменьшения движения отключает анимации.

Подсказки располагаются внутри чата над строкой ввода, на всю ширину экрана терминала. Экран сохраняет высоту, а при открытии меню прокручивается только чат. Длинный список команд также можно прокручивать внутри меню.

`/listen` открывает плеер. Кнопки на 3D-корпусе управляют воспроизведением, остановкой и переключением треков. Перетаскивание поворачивает корпус. Ниже — доступные с клавиатуры кнопки, перемотка и громкость. Закрытие останавливает звук, освобождает ресурсы 3D-сцены и сохраняет выбранный трек с позицией. Three.js загружается отдельно при открытии плеера.

## Структура

- `src/App.tsx` — приложение и открытие плеера.
- `src/components/Terminal.tsx` — ввод, подсказки и печатающиеся ответы.
- `src/components/PlayerPanel.tsx` — интерфейс плеера.
- `src/components/CassetteScene.tsx` — жизненный цикл 3D-сцены в React.
- `src/hooks/useAudioPlayer.ts` — воспроизведение и состояние аудио.
- `src/three/createPlayer.ts` — модель, освещение, катушки и кнопки.
- `src/lib/commands.ts` — определения и обработка команд.
- `src/config.ts` — ссылки и список треков.
- `src/styles.css` — оформление Phosphor и адаптивность.
- `public/audio/` — три оригинальных аудиофайла.
- `dist/` — создаётся командой `npm run build`; результат сборки, не исходники.

Треки better, free my mind и voyage сохранены без изменения содержимого. Для замены музыки обновить `public/audio` и `src/config.ts`. Ссылки GitHub/Bandcamp пока демонстрационные.

Проект работает локально. Публикация не выполнялась.
