# M0XXIE — Phosphor

Личный сайт-терминал на **React + TypeScript + Vite**, с кассетным плеером на Three.js и иконками React Icons (Feather и Simple Icons). Реализован выбранный первый вариант: зелёный CRT-экран и песочный Field Recorder FR–01 с чёрной кассетой.

## Локальный запуск

Требуется Node.js 22.12+ или 24+.

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:4173/. `npm start` запускает тот же сервер. Изменения отображаются автоматически.

```sh
npm test          # проверки терминала и аудиоуправления
npm run typecheck # строгая проверка TypeScript
npm run build     # готовая сборка в dist
npm run preview   # просмотр сборки после остановки dev-сервера
```

## Управление

Ввести `/` для подсказок. Команды: `/github`, `/music`, `/telegram`, `/player`, `/help`, `/clear`. Стрелки выбирают подсказки или возвращают историю ввода, Tab дополняет, Enter выполняет, Escape закрывает меню. Ответы печатаются посимвольно. Системная настройка уменьшения движения отключает анимации.

Подсказки располагаются внутри чата над строкой ввода, на всю ширину экрана терминала. Экран сохраняет высоту, а при открытии меню прокручивается только чат. Длинный список команд также можно прокручивать внутри меню.

`/player` открывает плеер. Кнопки на 3D-корпусе управляют воспроизведением, остановкой и переключением треков. Перетаскивание поворачивает корпус. Ниже — доступные с клавиатуры кнопки, перемотка и громкость. Закрытие останавливает звук, освобождает ресурсы 3D-сцены и сохраняет выбранный трек с позицией. Three.js загружается отдельно при открытии плеера.

## Структура

- `src/App.tsx` — приложение и открытие плеера.
- `src/components/Terminal.tsx` — ввод, подсказки и печатающиеся ответы.
- `src/components/PlayerPanel.tsx` — интерфейс плеера.
- `src/components/CassetteScene.tsx` — жизненный цикл 3D-сцены в React.
- `src/hooks/useAudioPlayer.ts` — воспроизведение и состояние аудио.
- `src/three/createPlayer.ts` — рендеринг, освещение и управление 3D-сценой.
- `src/three/buildFieldRecorder.ts` — корпус, кассета, катушки и кнопки FR–01.
- `src/lib/commands.ts` — определения и обработка команд.
- `src/config.ts` — ссылки на профили.
- `src/plugins/audioLibraryPlugin.ts` — автоматическое обнаружение аудиофайлов в `public`.
- `src/lib/loadTrackDurations.ts` — чтение длительности из метаданных файлов.
- `src/styles.css` — оформление Phosphor и адаптивность.
- `public/audio/` — аудиофайлы для плеера.
- `dist/` — создаётся командой `npm run build`; результат сборки, не исходники.

## Добавление музыки

Положить аудиофайлы в `public/audio/` (другие вложенные папки в `public/` тоже поддерживаются). Список формируется автоматически в алфавитном порядке: название совпадает с именем файла без расширения, артист всегда `m0xxie`. Никакие массивы в исходниках редактировать не нужно.

Распознаются MP3, WAV, OGG/OGA, M4A, AAC, FLAC, Opus и WebM; воспроизведение конкретного кодека зависит от браузера. Длительность всех треков считывается браузером из метаданных, по три файла одновременно, без запуска звука. До загрузки или при недоступных метаданных показывается `--:--`.

При локальной разработке добавление, удаление или замена аудиофайла автоматически перезагружает страницу. Для статической публикации после изменения файлов нужно заново выполнить `npm run build` и загрузить новую сборку: статический хостинг не предоставляет браузеру список папок.

GitHub: https://github.com/fil4tov. Ссылки на профили музыкальных площадок для `/music` задаются в `musicLinks` в `src/config.ts`.

Проект работает локально. Публикация не выполнялась.

Ссылка для `/telegram` задаётся в `links.telegram.url` в `src/config.ts`. Пока адрес пустой, название Telegram выводится без ссылки.
